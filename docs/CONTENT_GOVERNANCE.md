# Saylo 内容治理规则

## 1 内容进入条件

每条表达必须记录原形、常见变体、中文含义、语用功能、关系范围、正式程度、风险层级、来源社群、当前传播、中性替代和完整例句

高频日常表达必须连接到能够核对该交际功能的直接语法、课程或语料资料

根据 Saylo 测试版内容治理规则，来源敏感、快速变化或高风险表达需要至少 2 个相互独立的直接来源支持

公开视频、访谈、播客和公开社交内容可以证明实际使用，词典或语言研究资料用于核对含义、来源和语法

版权受限材料只记录必要的短例句、出处链接和改写后的教学例句

系统不会批量复制字幕、私聊或付费课程内容

## 2 风险分级

绿色表达可以在一般休闲交流中主动练习

课程仍然说明正式场景中的替代说法

黄色表达依赖关系、语气、地区、年龄、平台或来源社群

学习者先观察真实使用，再在熟悉关系中少量尝试

红色表达涉及较高冒犯、冲突、身份或语义漂移风险

课程以听懂和判断为主，主动使用需要真实社群教师确认

## 3 来源记录

来源社群说明表达形成或长期使用的社会背景

当前传播说明表达今天是否已经进入更广的美国口语或网络语境

两个字段必须分开维护

广泛传播不会抹去来源，社群来源也不会证明该社群的所有成员都使用这条表达

## 4 更新流程

- 第一步，收集最近真实语料并记录时间、平台、关系和上下文

- 第二步，由内容编辑核对含义、语气、来源、传播范围和可能伤害

- 第三步，由独立复核者检查例句能否在新语境中安全迁移

- 第四步，高风险或社群敏感表达交给具有相应经验的真实语言顾问复核

- 第五步，通过内容测试后更新数据版本，并记录发生变化的表达标识

- 第六步，执行 `npm run audit:content` 和 `npm run verify`，修正全部数量、重复、来源、答案和构建错误后再交付

## 5 每次变更后的自我审计

内容审计必须检查以下项目：

- 新增表达是否填补已经列明的会话功能缺口
- 主表达标识和标准化拼写是否重复
- 示例和复习参考答案是否实际使用目标表达
- 字面结构、表达来源和传播路径是否分开
- 来源链接是否存在于受控来源表
- 主动使用等级是否符合关系、语气和粗俗风险
- 对练场景是否只调用学习者已经学过的目标
- 页面中的表达数量、单元数量和文档统计是否与代码一致

审计发现缺口时，当前内容版本保持未完成状态，修正后重新执行完整审计

## 6 退役条件

表达含义明显漂移、真实使用快速减少、来源证据无法核实或风险超过教学收益时，内容编辑应把表达降为识别层或从主动课程移除

退役不会直接删除历史学习记录

表达标识继续保留，避免旧进度错误映射到其他内容

## 7 语音边界

语音反馈只评价可懂度、节奏、场景匹配和对话推进

系统禁止根据声音推断族裔身份，禁止要求学习者模仿族群口音，也禁止把自动语音识别结果当作唯一评分来源

## 8 当前版本状态

Saylo 内容版本日期为 2026-08-23，记录于本次工作区内容建立记录

Saylo 内容版本范围：301 条表达、26 个单元和 20 个角色任务的公开测试版内容

结构化检查状态：已经完成

真实美国英语教师外部审校状态：尚未完成

来源社群顾问外部审校状态：尚未完成

源码与测试版内容状态：公开可见，并明确标注尚未完成外部审校

正式教学内容状态：等待上述两项外部审校

部署访问状态：站点维护者可以通过兼容前向认证的身份代理限制访问范围
